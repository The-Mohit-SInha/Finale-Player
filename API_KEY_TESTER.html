🔑 YouTube API Key Tester

Test if your YouTube Data API v3 key is properly configured

How to Get a YouTube API Key:

Step 1: Google Cloud Console

Go to: https://console.cloud.google.com

Step 2: Create a Project

Click the project dropdown → "New Project" → Name it → Create

Step 3: Enable YouTube Data API v3

1. Go to "APIs & Services" → "Library"
2. Search for: YouTube Data API v3
3. Click on it and press "ENABLE"

Step 4: Create API Key

1. Go to "APIs & Services" → "Credentials"
2. Click "+ CREATE CREDENTIALS" → "API Key"
3. Copy the key (starts with AIza)

Step 5: Configure API Key (Important!)

1. Click "Edit API key"
2. Application restrictions: None
3. API restrictions: Restrict key → Select "YouTube Data API v3"
4. Save and wait 1-2 minutes

Step 6: Add to Supabase

1. Go to your Supabase project
2. Navigate to Edge Functions → Secrets
3. Create secret: YOUTUBE_MUSIC_API_KEY
4. Paste your API key
5. Save
